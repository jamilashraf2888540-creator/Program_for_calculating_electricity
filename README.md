⚡ برنامج حساب الكهرباء (Electricity Bill Calculator)
تطبيق أندرويد تم تطويره بلغة Java باستخدام Android Studio، مخصص لإدارة وحساب استهلاك الكهرباء لعدة عدادات، وتتبع القراءات السابقة واللاحقة، وحساب تكلفة الفاتورة بدقة وسهولة.

🚀 المميزات الرئيسية (Key Features)
إدارة متعددة للعدادات: إمكانية إضافة ومتابعة أكثر من عداد كهرباء باسم خاص بكل عداد.

الجلب التلقائي للقراءة السابقة: عند إضافة قراءة جديدة لأي عداد، يقوم التطبيق جلب القراءة الحالية السابقة تلقائياً لتسهيل الحسابات.

الحساب الفوري: حساب الاستهلاك بـ (kWh) وتكلفة الفاتورة الإجمالية (الاستهلاك × سعر الكيلوواط) بشكل آلي.

سجل القراءات (History): عرض سجل كامل لجميع قراءات العداد مع التواريخ والاستهلاك وتكلفة الفاتورة لكل فترة باستخدام RecyclerView.

عرض التفاصيل: إمكانية النقر على أي قراءة سابقة لعرض تفاصيلها الكاملة في شاشة مخصصة.

التوجيه الذكي: فحص قاعدة البيانات عند فتح التطبيق (MainActivity)؛ فإذا كانت المرة الأولى ولا توجد عدادات ينتقل لشاشة إضافة عداد، وإذا وجد عدادات مسبقة يتوجه مباشرة إلى القائمة الرئيسية.

📂 هيكلية المشروع والمكونات (Project Structure)
1. النشاطات (Activities)
MainActivity.java: نقطة البداية (Launcher)، تقوم بالتحقق من وجود عدادات مسجلة في قاعدة البيانات لتوجيه المستخدم بالشكل المناسب.

MeterListActivity.java: الشاشة الرئيسية التي تعرض قائمة العدادات المضافة مع دعم لحالة الفراغ (Empty State) في حال عدم وجود عدادات.

add_meter.java: شاشة إضافة عداد جديد مع قراءته الأولى وسعر الكيلوواط.

MeterHistoryActivity.java: شاشة سجل العداد، تعرض عدد القراءات وقائمتها، وتتيح الانتقال لإضافة قراءة جديدة.

add_reading.java: شاشة إضافة قراءة جديدة لعداد حالي (تقوم بجلب آخر قراءة مسجلة تلقائياً).

reading_result.java: شاشة عرض نتيجة الحساب الفورية بعد حفظ القراءة (الاستهلاك، السعر، والإجمالي).

ReadingDetailActivity.java: شاشة تفاصيل قراءة معينة عند النقر عليها من السجل.

2. محولات العرض (Adapters)
MeterAdapter: ربط وعرض قائمة العدادات في الشاشة الرئيسية مع آخر قراءة وتاريخ.

ReadingAdapter: ربط وعرض قائمة القراءات الخاصة بكل عداد داخل السجل.

3. قاعدة البيانات (Database)
Database.java: ملف إدارة قاعدة بيانات SQLite (ممتد من SQLiteOpenHelper) ويحتوي على جدولين رئيسيين:

جدول العدادات (meters): يحفظ معرف العداد (id) واسمه (name).

جدول القراءات (readings): يحفظ تفاصيل القراءات مربوطة بمعرف العداد (meter_id) وتشمل (القراءة السابقة، القراءة الحالية، الاستهلاك، سعر الكيلو، إجمالي الفاتورة، والتاريخ).

🛠️ التقنيات المستخدمة (Tech Stack)
اللغة: Java

بيئة العمل: Android Studio

قاعدة البيانات: SQLite

واجهات المستخدم: XML, Material Design Components, RecyclerView

📱 معاينة سريعة لتدفق الاستخدام (App Flow)
افتح التطبيق -> يتحقق من العدادات.

أضف عدادك الأول (اسم العداد + القراءة السابقة + القراءة الحالية + سعر الكيلو).

استعرض العدادات في القائمة الرئيسية وانقر على أي عداد لمشاهدة سجله الكامل.

أضف قراءات جديدة متتالية وسيتم حساب الفاتورة وتخزينها تلقائياً.
